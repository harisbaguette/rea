# 조사 기준

## 이 프로젝트만의 규칙과 계획

- 대상은 Decart의 Anywear Chrome 확장 프로그램이다. 같은 이름의 다른 서비스와 구분한다.
- 관찰한 배포 코드, 공식 문서의 설명, 그로부터의 추론, 확인하지 못한 서버 내부를 구분한다.
- 공개 API 요금은 이용자의 재구현 비용을 계산하는 데 쓴다. Anywear 운영사의 내부 원가로 해석하지 않는다.
- 코드에 있는 결제·무료 체험 경로는 기능 존재의 근거로만 쓴다. 실제 계정의 요금제와 이용 조건을 확정하지 않는다.
- 실제 사람의 카메라·얼굴·계정·쿠키·API 키를 수집하지 않는다. 원본 확장 프로그램을 설치하거나 실행하지 않는다.
- 원본 코드는 분석 자료로 보존한다. 재배포 또는 복제 구현의 허가를 받았다고 간주하지 않는다.
- 해시와 코드 위치, 분석 범위, 문서 출처는 evidence와 SOURCES.md에 분리한다.
- 실시간 품질·지연·GPU 원가는 직접 측정하지 못하면 미확인으로 남긴다.

## 완료 조건

- 영상 처리 위치와 입력부터 출력까지의 흐름을 배포 코드에 연결한다.
- 무료 제공과 낮은 자원 소모를 구분하고 공개 요금으로 계산한다.
- 얼굴 등으로 가능한 확장과 의류 전용 모델의 경계를 설명한다.
- 원본 무결성, 비용 계산, 근거 위치, 문서 연결을 오프라인에서 검증한다.
