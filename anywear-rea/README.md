# Anywear는 어떻게 실시간으로 옷을 입힐까?

**핵심은 쇼핑몰 이미지와 카메라 영상을 서버의 실시간 영상 생성 AI에 연결한 것이다.** 확장 프로그램은 카메라·상품 이미지·접속 상태를 다루고, Decart의 Lucy 모델이 영상을 변환한다. 사용자의 PC가 비교적 가벼워 보이는 이유는 큰 연산이 원격 서버에서 일어나기 때문이다.

무료 제공과 연산 비용은 별개다. Anywear는 베타 무료 이용을 안내하지만, 공개 API는 일반 모드에서 변환 시간 초당 $0.02를 받는다. 1분이면 $1.20, 8분이면 $9.60이다. 이 금액은 외부 개발자가 API를 쓸 때의 가격이며 Anywear의 내부 원가는 공개되지 않았다.

**얼굴·헤어·배경으로도 확장할 수 있다.** 범용 Lucy 2.5는 인물 교체, 머리색 변경, 배경 변경 등을 지원한다. 다만 안경·메이크업처럼 얼굴 위치를 따라 효과를 얹는 기능은 MediaPipe 기반의 로컬 처리도 비교할 만하다. 정교한 실사 변환과 가벼운 얼굴 필터는 필요한 기술과 비용이 다르다.
