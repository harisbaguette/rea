# 입어봄 화면 구조

할 일: 인물과 의상 이미지를 준비해 로컬 엔진의 피팅 결과를 비교하고 저장한다.
단계: 인물 선택 또는 카메라 촬영 → 의상과 종류 선택 → 엔진 연결과 생성 → 원본 비교와 저장.
요소: 모드 선택, 인물·의상 파일 입력과 미리보기, 카메라 켜기·촬영·끄기, 종류·상품 사진 유형, 라이브 프롬프트, 연결 상태·재연결, 생성·취소·초기화, 결과·비교·저장, 오류·복구와 임시 보관 안내.
주 행동: 피팅 이미지 만들기. 입력과 엔진이 준비되면 활성화하고 실행 중에는 같은 위치에 취소를 제공한다.

## 할 일

인물과 의상 이미지를 준비하고 로컬 추론 엔진에 피팅을 요청한 뒤 원본과 결과를 비교하고 저장한다. 엔진이 연결되지 않은 상태에서는 이미지 준비와 카메라 촬영까지 할 수 있다. AI 결과는 실제 엔진이 돌려준 경우에만 표시한다.

## 단계

1. 인물 사진을 선택하거나 카메라로 촬영한다.
2. 의상 이미지와 종류를 선택한다. 라이브 스타일 모드에서는 바꾸고 싶은 모습을 입력한다.
3. 엔진 연결을 확인하고 생성을 시작한다. 대기·실행·취소·실패 상태를 구분한다.
4. 원본과 결과를 비교하고 결과 파일을 저장한다.

## 요소

- 브랜드와 사진 피팅·라이브 스타일 모드 선택.
- 인물 이미지 선택·드롭·미리보기·교체·제거, 카메라 켜기·촬영·끄기.
- 의상 이미지 선택·드롭·미리보기·교체·제거, 의상 종류와 상품 사진 유형.
- 큰 결과 영역, 원본·결과 전환, 다운로드.
- 라이브 스타일 프롬프트와 예시.
- 엔진 연결 상태·모델 준비 상태·다시 연결.
- 생성·취소·작업 초기화, 진행 상태·오류·복구 안내.
- 사진은 메모리에만 머물고 새로고침 시 사라진다는 안내.

## 주 행동

사진 모드의 주 행동은 **피팅 이미지 만들기**다. 필요한 입력과 엔진이 준비됐을 때 활성화한다. 라이브 모드에서는 **라이브 시작**으로 바뀐다. 실행 중에는 취소 행동을 같은 위치에서 제공한다.

## 복구와 작은 화면

실패해도 사진과 설정을 보존하고 오류 가까이에 재시도를 둔다. 입력 변경·초기화·취소 뒤 도착한 이전 결과는 표시하지 않는다. 좁은 화면은 인물→의상과 설정→결과 순서로 배치한다. 키보드로 선택·생성·취소·저장할 수 있고 포커스를 보이게 한다.
