# 입어봄 공통 프런트엔드

인물·의상 사진 선택, 카메라 촬영, 모드와 설정, 로컬 엔진 연결, 작업 취소, 원본·결과 비교와 다운로드 화면이다. Mac과 Windows의 최신 Chrome·Edge를 대상으로 한다.

**추론 서버와 모델은 포함되지 않는다.** 엔진이 없어도 사진 준비와 카메라 촬영은 가능하다. AI 생성은 실제 엔진을 연결한 뒤 활성화된다. 테스트 응답은 제품에서 사용하지 않는다.

## 실행

Node.js 22.12 이상을 준비하고 이 폴더에서 실행한다.

```bash
npm ci
npm run dev
```

주소는 `http://127.0.0.1:5178`이다. 이미 다른 프로그램이 이 포트를 사용 중이면 기존 프로그램을 종료하지 않고 `npm run dev -- --port 5179`처럼 다른 포트로 실행한다.

개발 서버의 `/api`는 기본으로 `http://127.0.0.1:7861`에 연결한다. Windows에서 구현할 서버 규격과 순서는 상위 폴더의 `API_CONTRACT.md`, `WINDOWS_PLAN.md`, `CONTINUE_WINDOWS.md`를 따른다.

## 빌드와 검사

```bash
npm run build
npx playwright install chromium --only-shell
npm test
```

브라우저 시험은 별도 테스트 응답으로 프런트엔드의 성공·실패·취소 계약을 검사한다. 실제 모델의 결과 품질·GPU 속도를 검사하는 명령은 아니다.

사진은 브라우저 메모리에만 보관되며 새로고침과 초기화 시 사라진다. 이미지를 외부 서비스에 보내거나 원격 이미지 주소를 입력하는 기능은 없다.
