# 틈 디자인 시스템

휴가 날짜 → 여행지와 왕복 가격 → 운항 시각·판매처 확인 순으로 고른다. 일정과 가격이 화면의 중심이다. 공항 일러스트와 탑승권의 점선은 여행의 분위기를 만들고, 실제 정보와 조작 영역은 단순하게 유지한다.

토큰 원본은 `src/tokens.css`, 공용 요소는 `src/styles.css`, 움직임은 `src/motion.css`다.

| 체계 | 규칙 |
|---|---|
| 색 | 코발트 `--brand` #2453E8는 선택·주 행동, `--text` #172033은 날짜·가격. 흰 카드와 중립 배경 `--surface-page` #F5F7FB. 추천·선택 기간은 옅은 파랑, 상세 머리말은 `--boarding` #14367C |
| 글자 | 로컬 `Tteum UI`. 입력 16px 이상, 본문 14~16px, 보조 정보 12px 이상. 날짜 20~27px, 가격 24~32px. 금액·날짜를 생략하지 않음 |
| 간격 | 4px 배율. 카드 안 16px, 관련 요소 사이 8~12px, 구획 사이 24px |
| 모서리 | 카드·시트 `--radius-card` 16px, 입력·버튼 `--radius-control` 8px |
| 조작 영역 | `--target-size` 44px 이상. 기본 버튼 높이 `--control-height` 48px. 모바일 입력 16px |
| 아이콘 | 로컬 `/assets/icons.svg` 공용 스프라이트. 기본 20px, 보조 16px, 선 1.8px. 아이콘 버튼에는 행동을 설명하는 `aria-label` |
| 포커스 | 3px 테두리와 3px 간격. 이동 뒤 원래 카드·버튼과 목록 위치 복원 |
| 화면 폭 | 콘텐츠 최대 1240px. 1000px 이하는 목록 중심, 800px 이하는 한 열과 좌우 16px 여백 |
| 모션 | 누름 120ms, 단계 진입 280ms, 시트 240ms. 동작 줄이기에서는 이동·점멸 정지 |

## 행동과 아이콘

| 행동 | 아이콘·표현 |
|---|---|
| 날짜 선택·변경 | `calendar-days`와 짧은 라벨. 한 화면에 주 날짜 변경 버튼 하나 |
| 저장·저장 취소 | `bookmark`, `aria-pressed`, 선택 면. 삭제 뒤 되돌리기 |
| 필터 | `sliders-horizontal` + ‘필터’ + 적용 개수 |
| 내부 상세로 이동 | `chevron-right`. 카드 전체를 누르며 별도 CTA 줄을 반복하지 않음 |
| 외부 판매처 | `external-link`, 판매처 이름·왕복 금액과 함께 표시 |
| 캘린더 파일 | `calendar-plus`와 ‘캘린더’ |
| 정렬 | `arrow-up-down`과 현재 정렬 |
| 새로 조회 | `refresh-cw` |
| 시간 정보 | `clock-3`. 시각이 없는 항공권은 실제 체류시간 미확인으로 표시 |

## 컴포넌트

- `.search-toolbar`: 떠날 시기와 출발 공항을 둔다. 연차 개수는 필터에서 필요할 때만 바꾼다. 목적지가 나온 뒤에는 공항·필터·검색 버튼을 둔다.
- `.recommendation-strip`: 100~140px 여행 캐릭터, 공휴일 이름, 쉴 수 있는 기간과 연결할 연차를 묶는다. 날짜·휴가와 연차 칩·명확한 이동 버튼을 함께 둔다.
- `.window-option`: 휴가 기간·연차 칩과 실제 항공권 날짜·목적지·왕복 가격을 두 칸으로 비교한다. 가격이 없는 상태와 예산 초과는 구분한다.
- `.offer-option`: 같은 목적지의 짧고 저렴한 일정과 긴 일정을 같은 단위로 비교한다.
- 필터 시트: 예산·출귀국 날짜 간격·연차 연결·복귀 여유·지역·날짜 고정을 편집한다. 초기화도 적용 전에는 검색 상태를 바꾸지 않는다.
- 날짜 시트: 시작일과 마지막 날을 모두 고른 뒤 조회한다. 한 날짜를 누르는 행동이 결과 이동을 일으키지 않는다. 연결할 연차는 호박색과 + 기호, 공휴일은 붉은 면으로 구분한다. 공휴일 바로가기와 추천 기간 선택을 제공한다. 직접 입력과 키보드 방향키도 지원한다.
- 상세 시트: 왕복 가격 → 항공권 날짜 → 필요한 연차 → 선택적으로 펼치는 가격 근거 → 판매처. 같은 경로의 IATA 코드를 크게 반복하지 않는다.
- 오류·빈 상태: 이유와 가능한 다음 행동을 함께 둔다. 요금 재조회 실패 시 이미 받은 요금을 유지하고 이전 가격임을 표시한다.

단어를 줄이더라도 휴가 기간, 항공권 날짜, 왕복 금액, 수집 시각과 구매 전 확인할 조건은 구별한다. ‘최저’는 실제 비교한 일정·판매처 범위와 함께 표시한다. 판매처 가격의 차액을 평소 대비 할인율로 표현하지 않는다.

밝은 테마만 제공한다. 모바일에서는 연휴 찾기·달력·저장을 하단 메뉴로 사용하고 안전 영역을 비운다. hover 없이 과업을 끝낼 수 있어야 한다. 화면 확대·긴 도시명·로딩·빈 결과에서 날짜와 가격을 가리지 않는다.

검색 영역은 공항 그림과 흰 입력 면을 붙인다. 시기·공항을 선택한 뒤 파란 검색 버튼으로 적용한다. 입력 중에는 현재 결과의 출발지·기간을 유지한다. 추천은 옅은 파란 면, 날짜와 휴가·연차 칩, 큰 원형 화살표로 구별한다. 가격 목록은 흰 탑승권이며 날짜 앞에 달력 아이콘을 둔다. 모바일 메뉴는 하단, 데스크톱 메뉴는 상단이다.

색은 행동과 정보를 구별한다. 주 행동은 코발트, 날짜·가격은 진한 잉크색, 연차·주의는 호박색이다. 공항 그림 위에 홍보 문구를 겹치지 않는다. 결과의 왕복 단위·필터 조건은 한 줄로 묶고, 운항 시각 안내는 목록 위에 한 번만 둔다. 상세에는 시각 부재와 가격 변동 안내를 남긴다. 확인 시각은 가격 변동 안내와 함께 둔다. 저장 화면은 공통 메뉴로 이동한다.
