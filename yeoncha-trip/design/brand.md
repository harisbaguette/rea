# 틈

연차를 기준으로 여행할 날짜와 항공권을 고르는 서비스.

## 로고

- 기본: `/assets/brand/logo.svg`. 밝은 헤더에 63×36px 이상으로 배치한다.
- 영문: `/assets/brand/logo-en.svg`. 한글을 읽기 어려운 환경에서 쓴다.
- 심벌: `/assets/brand/symbol.svg`. 두 영역 사이로 열린 통로를 남긴다.
- 로고 주변에는 심벌 획 두께 이상의 여백을 둔다. 문구를 붙이거나 그림자·테두리를 더하지 않는다.
- 어두운 바탕에는 `symbol-mono.svg`를 흰색으로 사용한다. 색상을 CSS로 전달할 때는 SVG를 인라인으로 넣는다.

## 색과 서체

| 역할 | 값 |
|---|---|
| 브랜드·주 행동 | `#2453E8` |
| 본문·가격 | `#172033` |
| 기본 면 | `#FFFFFF` |
| 바탕 | `#EEF4FC` |
| 선택한 휴가 범위 | `#D9F47A` |

본문은 자체 호스팅한 Pretendard를 사용한다. 라임은 검은 글자와 함께 달력의 선택 범위에만 제한해 사용한다. 날짜와 가격이 장식과 설명보다 먼저 보여야 한다. 로고에는 별도 서체 파일이 필요 없다.

## 공항과 탑승권

첫 화면은 파란 공항 창 너머로 여행을 바라보는 장면이다. 본문은 흰 종이 탑승권의 곡선, 절취선, 날짜와 가격의 두 영역을 사용한다. 결과에서는 남색 일정표와 여행지 실사진으로 선택한 여행을 구별한다. 공항·고양이 일러스트는 분위기를 만들고, 실제 여행지·운항편을 나타내는 자료로 쓰지 않는다.

따뜻한 코럴은 일러스트의 작은 포인트다. 검색 조작과 정보에는 코발트, 남색, 흰색을 일관되게 사용한다. 비행편 번호·출발 시각·좌석·예약 확정처럼 제공되지 않는 정보를 탑승권 장식에 만들지 않는다.

## 웹 아이콘

- SVG 파비콘: `favicon.svg`
- PNG 파비콘: `favicon-16.png`, `favicon-32.png`
- ICO: `favicon.ico`
- Apple 터치 아이콘: `apple-touch-icon.png` — 180×180px
- 앱 아이콘: `icon-192.png`, `icon-512.png`

심벌을 더 작은 칸에 억지로 넣거나, 파비콘에 슬로건·글자를 함께 넣지 않는다.
