# 여행을 고르는 화면 전환

일정 → 여행지 → 판매처. 날짜·필요 연차·왕복 가격을 먼저 보여 준다.

| 장면 | 주인공과 화면 구성 | 행동과 복귀 |
|---|---|---|
| 연휴 선택 | 밝은 화면, 간결한 조건 요약 아래 세로 일정 목록·왕복 가격 | 모바일은 카드 전체가 화면 안에 들어온다. 선택한 카드와 목록 위치를 기억한다. |
| 여행지 비교 | 여행지 사진·이름, 짧게/길게 두 가격 비교 | 선택 일정은 간결한 요약으로 남긴다. 다른 일정 보기로 원래 카드와 목록 위치에 돌아간다. |
| 항공권 상세 | 현재 왕복 가격·날짜·필요 연차, 판매처 순 | 닫기와 브라우저 뒤로 가기는 같은 카드와 스크롤 위치로 돌아간다. |
| 직접 날짜 선택 | 검색창의 직접 선택, 출발일·귀국편 출발일, 휴가·연차 칩 | 선택 중인 공항과 날짜를 함께 검색한다. 취소하면 이전 조건을 유지한다. |
| 저장한 여행 | 저장한 날짜·목적지·가격, 현재 운임 확인 | 저장 취소는 즉시 반영하고 같은 위치를 유지한다. |
| 여행 필터 변경 | 예산·숙박·복귀 여유 시트, 초기화와 적용 버튼 | 적용하기 전에는 조회하지 않는다. 닫으면 원래 조건 버튼으로 돌아간다. |
| 연휴 정렬 | 선택 표시가 있는 짧은 항목 목록 | 항목을 고르면 목록 순서만 바꾼다. |
| 연차 일정 | 날짜 타임라인, 연차 신청일, 저장·캘린더 버튼 | 주 화면에서 필요할 때 열고 닫는다. |
| 운임·운항 정보 | 귀국편 날짜·왕복 요금·판매처 연결 범위 세 항목 | 구매 판단의 제한은 판매처 곁에서도 짧게 보여 준다. |

목록은 같은 틀을 반복해 비교한다. 조건 입력·가격 비교·판매처 선택은 서로 다른 구성으로 다음 행동을 구별한다.

## 움직임 계약

| 대상 | 표현 | 시간 |
|---|---|---|
| 연휴·여행지·저장 화면 | View Transition으로 내용 교체, 메뉴 위치 유지 | 200ms |
| 미지원 브라우저·뒤로 가기 | 아래에서 짧게 등장 | 160ms |
| 상세·달력 | 모달 등장과 배경 흐림 | 180ms |
| 추천 고양이 | 첫 등장에만 짧게 착지 | 460ms |
| 가격 조회 대기 | 여행 가방과 작은 비행기, 티켓 스켈레톤 | 실제 응답까지 |
| 저장 | 책갈피 스탬프 | 300ms |
| 동작 줄이기 | 즉시 표시, 반복 움직임 정지 | 0ms |

화면 전환은 요금 응답을 기다리지 않는다. 이전 요청은 새 검색 결과를 덮을 수 없다. 그림·가격 갱신 때마다 등장 효과를 반복하지 않는다. 가짜 진행률과 완료 시간은 표시하지 않는다.

시기와 공항을 바꿔도 검색 전에는 결과와 URL을 유지한다. 검색 중에는 중복 제출을 막되, 새 조건으로 바꾸면 다시 검색할 수 있다. 같은 조건 재조회는 기존 가격을 유지하고 다른 조건 검색은 이전 가격을 지운다.

모바일은 하단 메뉴, 데스크톱은 상단 메뉴를 쓴다. 단계 이동 시 결과 제목으로 포커스를 옮기고, 연휴 목록에 돌아오면 원래 위치와 선택 카드를 복원한다. 검색·추천·가격 목록은 서로 다른 면과 여백으로 구분한다.

직접 입력한 일정은 고른 출발일과 귀국편 출발일 그대로 검색한다. 복귀 여유를 빼거나 더 짧은 날짜로 바꾸지 않는다. 해당 날짜의 요금이 없으면 날짜 변경과 기간 내 재검색을 제공한다. 귀국편 출발일은 한국 도착일과 다를 수 있으며 운항 시각은 판매처에서 확인한다.
