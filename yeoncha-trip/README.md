# 틈 — 연차로 떠나는 여행

쓸 수 있는 연차로 연휴를 찾고, 연휴마다 실제 수집 요금과 여행 기간을 비교합니다. 같은 목적지에서도 저렴하게 다녀오는 일정과 더 오래 머무는 일정을 함께 고를 수 있습니다.

- 2026·2027 공휴일·주말·연차와 2026년 말부터 2027년 초까지 이어지는 휴가
- 연휴별 최저 수집 요금·가장 긴 여행 요약, 점진 조회와 개별 재시도
- 같은 목적지의 싼 일정·긴 여행을 가격 차이와 필요 연차로 비교
- 월별 요금·연휴 정렬, 최소 숙박·왕복 예산·지역·날짜 고정 필터
- 인천·김포·김해·제주·대구·청주 출발, 모든 조회 가능 목적지
- 판매처별 수집 요금·가격 이력·같은 일정의 판매처 검색 연결
- 상세 뒤로 이동·조건을 유지하는 URL 공유·여행 저장·캘린더 다운로드

현재 배포는 본인만 접속할 수 있는 검증 사이트입니다. 일반 이용자 공개와 정확한 한국 도착 시각을 이용한 복귀 판단에는 아래 데이터 공급 조건의 확정과 연동이 남아 있습니다.

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev
```

개발 주소는 `http://127.0.0.1:4179`입니다. 다른 포트는 `PORT=4180 npm run dev`로 지정합니다.

## 빌드와 배포

```sh
npm run build
npm run preview
```

빌드 결과인 `dist/server/index.js`는 서버와 에셋을 모두 포함한 Cloudflare Worker ESM입니다. 정적 파일만 올리면 운임 조회가 동작하지 않습니다. Sites에서는 `.openai/hosting.json`의 기존 프로젝트를 유지하고 Worker 배포물을 저장·배포합니다.

일반 Cloudflare Workers로 배포하려면 계정에 로그인한 뒤 실행합니다.

```sh
npx wrangler deploy
```

배포 도메인을 바꾸면 `index.html`의 `og:url`과 `og:image` 주소도 바꿉니다.

## 검사

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run test:live
```

`test:e2e`는 조회 상태·대안 선택·뒤로 이동·공유·저장·접근성을 통제된 응답으로 검사합니다. `test:live`는 실제 운임 제공처를 호출합니다. 기존 Chromium을 쓰려면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 지정합니다.

## 운임과 복귀 날짜

가격은 Catchfrog 공개 조회에서 받은 성인 1명·일반석·왕복 수집 운임입니다. 최저가와 가장 긴 여행은 조회된 범위의 값입니다. 미수집·빈 결과·조회 실패를 구분하고, 갱신 실패 때 이전 값이 남으면 오래된 운임임을 표시합니다. 원본의 요청 제한이 발생하면 안내된 대기 시간 뒤 다시 조회합니다.

판매처 연결은 같은 공항·날짜의 검색을 엽니다. 표시 가격과 특정 항공편의 예약 가능 여부는 판매처에서 다시 확인해야 합니다.

귀국 날짜는 **귀국편 출발일**입니다. 현재 운임 응답에는 편명·정확한 출발/도착 시각·경유·수하물·offer ID가 없어 한국 도착일과 출근 가능 여부를 확정할 수 없습니다. 기본값인 복귀 여유 하루는 일정 계산을 위한 설정입니다.

## 일반 제공에 필요한 데이터 공급 조건

공급자에게 다음 항목을 확인하고 사용 가능한 계약·계정의 연동을 승인해야 합니다.

- 가격 재표시·일반 이용자 제공·제휴 링크 사용 허용 범위
- 서버 전체 호출 한도, 캐시 보관 조건, 요청 제한과 재시도 정책
- 같은 offer ID에 연결된 편명·출발/도착 시각과 시간대·경유·수하물
- 해당 offer의 가격 재확인·유효기간·판매처 연결 방법

서로 다른 공급자의 운항 시각과 가격을 노선·날짜만으로 합치지 않습니다. 제공처의 공개 조회 중단이나 형식 변경으로 검색이 중단될 수 있습니다.

저장한 여행은 이 브라우저에만 보관합니다. 예약·결제·계정·가격 알림 발송은 처리하지 않습니다.
