# 틈 — 연차로 떠나는 여행

쓸 수 있는 연차로 연휴를 먼저 찾고, 그 연휴 안에 다녀오는 실제 수집 항공권을 비교합니다.

- 2026·2027 공휴일·주말·연차로 만드는 여행 가능 기간
- 연휴 안에서 가장 저렴한 일정 또는 출발·귀국편 날짜 고정
- 인천·김포·김해·제주·대구·청주 출발, 모든 조회 가능 목적지
- 최소 숙박일·왕복 예산·지역·노선 평균 대비 가격 필터
- 판매처별 실제 수집 요금, 같은 일정의 가격 이력 그래프
- 판매처 예약 연결, 여행 저장, 캘린더 다운로드

## 실행

Node.js 20 이상이 필요합니다.

```sh
npm ci
npm run dev
```

개발 주소는 `http://127.0.0.1:4179`입니다. 다른 포트는 `PORT=4180 npm run dev`로 지정합니다.

## 빌드와 배포

```sh
npm run build
npm run preview
```

빌드 결과인 `dist/server/index.js`는 서버와 에셋을 모두 포함한 Cloudflare Worker ESM입니다. 정적 파일만 올리면 운임 조회가 동작하지 않습니다. Sites에서는 `.openai/hosting.json`의 기존 프로젝트를 유지하고 Worker 배포물을 저장·배포합니다.

일반 Cloudflare Workers로 배포하려면 계정에 로그인한 뒤 실행합니다.

```sh
npx wrangler deploy
```

배포 도메인을 바꾸면 `index.html`의 `og:url`과 `og:image` 주소도 바꿉니다.

## 검사

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run test:live
```

`test:e2e`는 조회 실패·응답 순서·저장·접근성을 통제된 응답으로 검사합니다. `test:live`는 실제 운임 제공처를 호출해 날짜 경계·가격 이력·판매처 연결을 검사합니다. 기존 Chromium을 쓰려면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 지정합니다.

## 운임과 복귀 날짜

운임 제공처의 공개 조회 결과를 표시하며 예시 가격은 사용하지 않습니다. 수집 시각과 조회 실패를 구분하고, 갱신 실패 때 이전 값이 남으면 오래된 운임임을 표시합니다. 최종 운임·좌석·수하물은 판매처에서 확인해야 합니다.

귀국 날짜는 **귀국편 출발일**입니다. 한국 도착일이 다음 날일 수 있어 복귀 여유 하루가 기본으로 설정됩니다. 장거리·경유편의 도착 시각과 추가 연차는 판매처에서 확인합니다.

제공처가 공개 조회를 중단하거나 형식을 바꾸면 검색이 중단될 수 있습니다. 독립 데이터 수집망과 유료 공급 계약은 포함하지 않습니다. 공개·상업 확장 전에는 운임 데이터 제공 조건과 제휴 관계를 별도로 확정해야 합니다.

저장한 여행은 이 브라우저에만 보관합니다. 예약·결제·계정·가격 알림 발송은 처리하지 않습니다.
