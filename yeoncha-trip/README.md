# 틈

공휴일과 연차로 쉴 날짜를 고르고, 여행지와 실제 항공편을 비교하는 사이트입니다.

[사이트 열기](https://air.bluekite.co.kr)

1. 추천 연휴나 직접 날짜를 고릅니다.
2. 날짜별 참고 가격을 비교하거나 ‘여행지 직접 선택’으로 목적지를 찾습니다.
3. 출국편과 귀국편을 고르면서 시각·경유·대기시간·실제 체류시간을 비교합니다.
4. 현재 가격을 다시 확인하고 선택한 항공편의 Google 판매처 화면으로 이동합니다.

경유 횟수, 항공사, 출도착 시간, 최대 이동·대기시간, 왕복 예산, 최소 체류시간, 한국 도착 마감을 설정할 수 있습니다. 공유 주소에는 공항·날짜·여행지가 유지됩니다. 저장한 여행은 현재 기기의 브라우저에 보관합니다.

## 실행

Node.js 22 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

주소는 `http://127.0.0.1:4179`입니다. 포트는 `PORT=4180 npm run dev`로 바꿉니다.

## 빌드·배포

```sh
npm run build
npm run preview
```

`dist/server/index.js`는 에셋과 서버를 포함한 Cloudflare Worker입니다. 정적 파일만 배포하면 운임 조회가 동작하지 않습니다.

Wrangler로 Cloudflare에 로그인한 뒤 배포합니다. 빌드는 배포 명령에서 자동으로 실행합니다.

```sh
npm run deploy
```

`wrangler.toml`의 `tteum-leave-trip` Worker와 `air.bluekite.co.kr` 도메인으로 배포합니다. 인증서는 Cloudflare에서 관리합니다.

## 검사

```sh
npm test
npm run build
npm run test:artifact
npm run test:public
```

항공편 원본을 실제로 호출하는 검사는 다음과 같습니다. 미래의 출국·귀국편 날짜를 넣습니다.

```sh
node scripts/itinerary-check.mjs --base http://127.0.0.1:4179 --origin ICN --code NRT --start 2026-11-05 --end 2026-11-08
```

## 데이터와 제공 범위

연휴·여행지 목록은 Catchfrog의 날짜별 참고 가격입니다. 항공편 상세는 Google 항공편 공개 검색을 조회합니다. 출국편의 가격은 왕복 시작가이며, 귀국편 선택 후 해당 두 항공편의 왕복 가격을 표시합니다. 서로 다른 제공처의 가격과 시각을 합치지 않습니다.

항공편 조회는 API 키 없이 동작하지만 공식 제휴 API가 아닙니다. 공개 페이지 형식 변경·조회 제한 시 실패를 표시하며 임의 항공편이나 시험 가격으로 대체하지 않습니다. 일반 제공·재표시·캐시 조건은 별도 확인이 필요합니다.

시각은 예정 운항 시각입니다. 현지 체류는 목적지 도착부터 귀국편 출발까지, 귀국 마감은 한국 시각으로 계산합니다. ‘낮 시간’은 현지 08–22시에서 공항 전후 각 2시간을 제외한 추정치입니다. 수하물·변경·환불 조건과 최종 금액은 판매처에서 확인합니다. 예약·결제·가격 알림 발송은 처리하지 않습니다.
