# 틈 운영

공유 주소: https://air.bluekite.co.kr

## 상태 확인

```sh
node scripts/public-check.mjs
```

로그인 화면과 비로그인 접근 차단을 확인합니다. 외부 운임을 호출하지 않습니다. 실패한 경로와 상태 코드를 출력합니다.

실제 항공권 조회와 판매처 이동은 다음 명령으로 확인합니다. 운임 제공처를 호출하므로 반복 실행하지 않습니다.

```sh
node scripts/access-browser-check.mjs
```

비밀번호는 화면에 표시되지 않는 입력란에서 받습니다. 항공편과 왕복 가격의 연결은 `node scripts/itinerary-check.mjs --start YYYY-MM-DD --end YYYY-MM-DD`로 확인합니다. 출국편 조회·귀국편 조회·가격 재확인으로 원본을 최대 3회 호출합니다.

## 비밀번호와 접근 제한

```sh
node scripts/access-secret.mjs --set
```

비밀번호를 바꾸면 기존 로그인도 모두 만료됩니다. 비밀번호 원문은 저장하지 않으며, 검증값과 서명 키는 Cloudflare Secrets에 보관합니다. 명령 인자·소스·문서에 비밀번호를 넣지 않습니다.

- 로그인: 8시간 후 만료, 로그아웃 즉시 해당 세션 폐기.
- 로그인 시도: IP별 15분에 8회·전체 80회. 비밀번호 실패가 IP별 4회·전체 20회 쌓이면 Cloudflare Turnstile 확인이 필요합니다. 정상 입장은 실패 횟수에 포함하지 않습니다.
- 자동 입력 확인: Cloudflare 위치별로 IP당 분당 10회. 저장소에 주소를 쌓지 않아 남의 시도가 내 확인을 막지 못합니다. Cloudflare 확인 서버가 응답하지 않으면 확인 전 한도로 처리합니다. 확인용 테스트 키는 운영 도메인에서 거부합니다. 사이트 키는 `wrangler.toml`의 `TURNSTILE_SITE_KEY`, 비밀 키는 Secrets의 `TURNSTILE_SECRET`입니다.
- 입장했던 브라우저: 90일 동안 기기 쿠키를 받아 전체 한도와 사람 확인 없이 기기별 15분에 8회로 입장합니다. 공격자가 전체 한도를 다 써도 주인 브라우저는 들어올 수 있습니다. 비밀번호를 바꾸면 기기 쿠키도 모두 무효가 됩니다.
- IPv6는 /64 대역을 한 주소로 셉니다.
- 비밀번호 기준: 운영자가 정한 8자 비밀번호를 씁니다. 길이가 짧은 대신 시도 횟수 제한과 Turnstile 확인으로 대입 공격을 막습니다.
- 로그인 성공·실패·차단은 IP 없이 `{"event":"auth"}` 로그로 남습니다.
- API: 세션별 분당 30회, 전체 분당 120회·24시간에 3,000회.
- 실제 외부 조회: 전체 분당 120회·시간당 1,200회·24시간에 5,000회. 동시 6개, 개별 요청 최대 20초·응답 6MB.
- 비로그인 요청은 항공권 공급자를 호출하지 않습니다. 상태 저장소 장애 시 접근을 차단합니다.

전역 제한은 SQLite Durable Object가 집계합니다. 추가로 Cloudflare 위치별 IP 요청 제한을 적용합니다. 위 수치는 공급자 요청의 상한이며, 외부에서 들어오는 모든 HTTP 요청의 과금 상한은 아닙니다. WAF 규칙 변경에는 별도 Cloudflare 권한이 필요합니다.

이전 `chatgpt.site` 주소는 소유자만 접근하도록 유지합니다. 접근 보호 이전의 배포 버전으로 롤백하면 안 됩니다.

## 장애 대응

- 429: 제공처의 `Retry-After`가 끝날 때까지 재시도하지 않습니다.
- 요금 조회 실패: 신규 요금 조회가 실패하면 30분 이내의 캐시만 ‘이전 가격’으로 보여 줍니다. 오래된 가격을 최신 가격으로 바꾸어 표시하지 않습니다.
- 판매처 연결 실패: 오류 화면의 다른 판매처 검색을 이용할 수 있습니다.
- 항공편 원본 제한·형식 변경: `FLIGHT_SOURCE_BUSY` 또는 `FLIGHT_SOURCE_UNAVAILABLE`을 표시합니다. 403·429는 60초, 원본 구조 미확인은 30초 동안 재요청을 줄입니다. 차단 우회나 빈 결과로의 대체는 하지 않습니다.
- 코드 배포 장애: `wrangler deployments list`로 접근 보호가 적용된 이전 정상 버전을 확인하고 `wrangler rollback <버전ID>`로 복구합니다.
- 데이터 제공 중단·권리 문제·보안 사고: Cloudflare에서 항공권 Worker의 도메인 연결을 일시 중단하고 원인을 확인합니다. 사용자 토큰이나 IP 주소가 포함된 로그를 공유하지 않습니다.

배포는 `npm run deploy`, 오류 로그는 `wrangler tail --format json`으로 확인합니다. 계정 인증은 Wrangler 로그인을 사용합니다.

항공편 조회 캐시는 60초이며 가격 재확인은 캐시를 건너뜁니다. 완료된 응답만 최대 32개 저장하고 한 인스턴스에서 동시 조회 3개를 허용합니다.

운임 캐시는 Worker 인스턴스 단위이며, 전역 호출 제한은 캐시에서 찾지 못해 실제 공급자를 호출할 때 적용합니다. 한도는 `server/access-guard.js`의 `LIMITS`에서 조정합니다.

## 정식 운영 전 필요한 정보

- 운영자명과 개인정보·서비스 문의 연락처
- 호스팅 로그의 처리 범위·보관 기간·위탁 조건
- 운임 데이터 재표시·제휴 링크·서버 조회·캐시 이용 조건
- 공개 페이지 대신 안정적인 제휴 공급자를 사용할 경우 계약·자격증명

신청·계약·결제 정보와 비밀키를 소스나 문서에 넣지 않습니다. 확인하지 않은 공급 조건을 공개 허가로 간주하지 않습니다. 예약·결제·환불은 판매처에서 처리합니다.
