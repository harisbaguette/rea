
REA 체험 · 실행 파일 속 배송비 규칙 찾기

자체 제작한 연습용 프로그램입니다. 실행 파일만 REA에 전달합니다.

1. 계산기를 먼저 실행해 보세요.
주문금액 [기본 32000원]: 0~100000000 사이의 정수를 입력하세요.
주문금액 [기본 32000원]: 회원인가요? [Y/n]: y 또는 n을 입력하세요.
회원인가요? [Y/n]: 
주문 32,000원 / 회원
배송비 0원 → 결제금액 32,000원

2. Enter를 누르면 REA로 숨겨진 조건을 분석합니다. 
실제로 실행하는 REA 명령:
/Users/haris/.local/bin/rea decompile '/Users/haris/Desktop/REA/실행관리(Ops-Run)/분석 대상/shipping-demo' _shipping_fee --provider ghidra --json

REA가 실행 파일에서 복원한 의사 코드:

undefined4 _shipping_fee(int param_1,int param_2)

{
  undefined4 local_4;
  
  if ((param_1 < 50000) && ((param_2 == 0 || (param_1 < 30000)))) {
    local_4 = 0xdac;
  }
  else {
    local_4 = 0;
  }
  return local_4;

param_1은 주문금액, param_2는 회원 여부(0 또는 1)입니다.
16진수 0xdac는 10진수로 3500입니다.

3. 회원의 최소 무료 배송 주문금액은 얼마일까요? [Enter: 해설 보기]: 맞았습니다.

코드를 해석하면 다음과 같습니다.
• 50000원 이상이면 무료 배송
• 회원은 30000원 이상이면 무료 배송
• 그 외 배송비는 3500원
